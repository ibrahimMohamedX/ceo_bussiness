# PROJEX Spacing System
Version: 1.0

---

# Purpose

Define one unified spacing scale across the entire website.

Consistency in spacing is one of the strongest indicators of premium design.

Never use random spacing values.

---

# Base Unit

8px

Every spacing value should be a multiple of 8 whenever possible.
