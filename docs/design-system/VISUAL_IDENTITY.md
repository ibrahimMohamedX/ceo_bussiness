# PROJEX Visual Identity System
Version: 1.0

---

# Purpose

This document defines the official visual language of the PROJEX website.

Every page, section and component must follow these rules.

Never introduce a different visual style.

Consistency is more important than creativity.

---

# Brand Personality

PROJEX should feel like:

• Engineering-first
• Intelligent
• Premium
• Precise
• Modern
• Technical
• Innovative
• Trustworthy

The design should communicate confidence through simplicity.

---

# Visual Inspiration

The overall experience should sit between:

Apple
NVIDIA
Linear
Vercel

Not by copying them,
but by combining their strongest characteristics.

Apple
→ premium product presentation

NVIDIA
→ engineering precision

Linear
→ clean interface

Vercel
→ spacing and typography

---

# Design Principles

Everything should feel:

Calm

Balanced

Structured

Intentional

Elegant

Minimal

Every element must have a purpose.

# Forbidden Colors

Do not use:

Bright Red

Bright Orange

Bright Green

Rainbow gradients

Warm yellow UI

Gold

Pink

Unless required for data visualization.

---

# Gradient Rules

Use gradients only when necessary.

Primary Gradient

Cyan → Purple

Direction:

135°

Opacity:

Subtle

Never create rainbow gradients.

---

# Background Style

Dark premium.

Very subtle gradients.

Soft radial lighting.

No noisy textures.

No carbon fiber.

No gaming backgrounds.

---

# Grid System

Use a 12-column layout.

Maximum content width:

1440px

Default content width:

1280px

Responsive spacing must remain proportional.

---

# Border Radius

Buttons

16px

Cards

24px

Sections

32px

Glass Panels

28px

Avoid sharp corners.

---

# Border Style

Use:

1px solid rgba(255,255,255,0.08)

Hover:

rgba(53,226,255,0.18)

Never use thick borders.

---

# Shadows

Very soft.

Large blur.

Low opacity.

Never create dark heavy shadows.

Shadow should suggest depth, not weight.

---

# Glassmorphism

Use sparingly.

Opacity:

4%–8%

Blur:

16–24px

Glass is an accent,
not the primary style.

---

# Glow Rules

Glow is used only to enhance:

Engineering Core

Primary Button

Icons

Highlights

Never apply glow to entire sections.

Never glow paragraphs.

Never glow cards excessively.

---

# Typography

Primary Font

Geist

Fallback

Inter

Weights:

400

500

600

700

Never use decorative fonts.

---

# Heading Style

Large

Bold

Compact

Confident

Maximum line width:

12 words

Never create very long headings.

---

# Body Text

Readable.

Comfortable.

High contrast.

Maximum width:

70 characters.

---

# Icons

Use outline icons.

Simple geometry.

Consistent stroke width.

Avoid colorful icons.

Avoid emoji.

---

# Images

Use:

3D renders

Engineering visuals

Abstract technology

Product quality renders

Avoid:

People typing

Stock laptops

Generic office photos

AI robots

Floating code screenshots

---

# Components

Every component should share:

Same radius

Same spacing

Same border

Same hover logic

Same animation language

---

# White Space

Whitespace is part of the design.

Never fill every area.

Luxury products breathe.

---

# Consistency Rules

If two components solve the same problem,
they should look related.

Avoid visual randomness.

---

# Do

✓ Keep layouts clean.

✓ Use consistent spacing.

✓ Respect the grid.

✓ Keep glow subtle.

✓ Use engineering visuals.

✓ Preserve negative space.

---

# Don't

✗ Don't create gaming UI.

✗ Don't overuse gradients.

✗ Don't use oversized icons.

✗ Don't use random neon.

✗ Don't create visual clutter.

✗ Don't imitate cyberpunk.

---

# Acceptance Criteria

✓ Every page feels like part of one product.

✓ Users recognize the PROJEX identity immediately.

✓ Visual hierarchy is always clear.

✓ Engineering aesthetic is maintained.

✓ Premium feeling is preserved.

✓ No section feels disconnected.
