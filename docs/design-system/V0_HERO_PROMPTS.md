# PROJEX Hero Build Workflow

Never generate the hero in one step.

Build it incrementally.

---

STEP 1

Create the hero layout only.

No assets.

No animations.

No effects.

Only:

Two-column responsive layout.

Correct spacing.

Typography.

Buttons.

Empty hero visual container.

Stop after finishing.

---

STEP 2

Import all hero assets.

Position every asset according to the Hero Composition document.

Do not animate.

Do not redesign.

Only compose the scene.

Stop.

---

STEP 3

Apply depth.

Correct z-index.

Opacity.

Blend modes.

Layer hierarchy.

No motion yet.

Stop.

---

STEP 4

Add subtle animations.

Floating.

Ring rotation.

Glow breathing.

Particle drifting.

Mouse parallax.

Respect Motion System.

Stop.

---

STEP 5

Optimize.

Responsive.

Accessibility.

Performance.

Image optimization.

Lazy loading.

Stop.

---

STEP 6

Polish.

Improve spacing.

Improve alignment.

Improve visual balance.

Do not redesign.

Only refine.

End.
