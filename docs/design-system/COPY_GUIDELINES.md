# PROJEX Copy Guidelines

Tone:
- Engineering-first
- Premium
- Confident
- Precise
- Human
- Calm

Avoid:
- World-class
- Cutting-edge
- Revolutionary
- Best-in-class
- We are experts
- Buzzwords

Headlines:
- Maximum 12 words.

Descriptions:
- Maximum 2–3 sentences.

CTAs:
- Start with action verbs.

Write for technical decision makers, not consumers.
