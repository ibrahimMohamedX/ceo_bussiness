# PROJEX Hero Composition Blueprint
Version: 1.0

---

# Purpose

This document defines the exact composition of the PROJEX homepage hero.

This is NOT a design suggestion.

Treat every instruction below as part of the official design system.

Do not redesign.

Do not simplify.

Do not replace assets with generic illustrations.

---

# Hero Philosophy

The hero represents Engineering Intelligence.

Everything must feel:

• Premium
• Futuristic
• Scientific
• Precise
• High-end
• Calm
• Minimal
• Powerful

Avoid:

- Gaming UI
- Cyberpunk overload
- Neon chaos
- Glassmorphism everywhere
- Cartoon style
- Heavy gradients
- Random glowing objects

Every visual element must have engineering purpose.

# Engineering Core

The Core is the heart of the entire hero.

It represents:

Engineering

Software

Embedded

Artificial Intelligence

Everything revolves around it.

Nothing should overlap the center logo.

---

# Rings

Floating rings orbit around the core.

They must never intersect physically.

Each ring has a different size.

Different opacity.

Different blur.

Different glow intensity.

Slow independent movement.

---

# Neural Network

Position:

Top section.

Connected visually to the Core.

Should feel suspended.

Not attached.

Nodes:

Large center node.

Medium nodes.

Small nodes.

Thin glowing connections.

No random shapes.

---

# Data Flow

Must begin beneath the platform.

Travel upward.

Feed energy into the Core.

Never move sideways only.

Movement should imply:

Data

Power

Signal

Engineering

---

# Holographic Grid

Perspective grid.

Fades near screen edges.

Very subtle.

Never compete with text.

Opacity:

5%–10%

---

# Glow Rules

Glow is additive.

Never blur everything.

Each asset owns its own glow.

Use multiple glow layers instead of one large glow.

---

# Visual Density

High density.

---

# Empty Space

Negative space is intentional.

Do not fill every area.

Luxury products use empty space.

---

# Hero Composition Goal

When someone opens the website, the first reaction should be:

"This looks like an engineering company building the future."

Never:

"This looks like a gaming website."

Never:

"This looks like an AI image."

The final hero should feel like a premium product launch by a world-class engineering company.
