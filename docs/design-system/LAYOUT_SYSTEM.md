# PROJEX Layout System
Version: 1.0

---

# Purpose

This document defines the structural layout system for the PROJEX website.

Every page must follow the same spatial logic to maintain consistency, scalability and readability.

---

# Layout Philosophy

The layout should feel:

• Spacious
• Structured
• Predictable
• Premium
• Engineering-focused

Avoid dense layouts and unnecessary complexity.

---

# Grid System

Desktop:
12-column grid

Tablet:
8-column grid

Mobile:
4-column grid

Use CSS Grid whenever appropriate.

# Alignment

Always align content to the grid.

Avoid random offsets.

Use left alignment for text.

Center only when required.
